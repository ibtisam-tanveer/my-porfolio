# Portfolio Website - Resume Bullet Points

## Short Version (1-2 bullets)
- Developed a full-stack interactive portfolio website with AI-powered RAG (Retrieval-Augmented Generation) chat system using Next.js 16, React 19, FastAPI, and ChromaDB vector database
- Implemented macOS-inspired desktop interface with custom window management, semantic search capabilities, and integration with OpenAI/Anthropic LLMs via LangChain

## Detailed Version (3-4 bullets)
- Architected and developed a full-stack portfolio website featuring a macOS-inspired desktop environment with custom window management system, built with Next.js 16, React 19, TypeScript, and Tailwind CSS
- Designed and implemented a RAG (Retrieval-Augmented Generation) system using FastAPI, ChromaDB vector database, and LangChain, enabling semantic search over portfolio data with context-aware AI responses
- Integrated OpenAI GPT and Anthropic Claude LLMs with a flexible, provider-agnostic architecture, implementing document chunking, vector embeddings, and conversation history management
- Created an immersive user experience with Three.js/React Three Fiber for 3D graphics, Framer Motion animations, and a terminal-style chat interface with real-time query processing

## Technical Skills Highlighted
- **Frontend**: Next.js, React, TypeScript, Tailwind CSS, Three.js, Framer Motion
- **Backend**: FastAPI, Python, ChromaDB, LangChain, OpenAI API, Anthropic API
- **AI/ML**: RAG systems, vector embeddings, semantic search, LLM integration
- **Architecture**: RESTful APIs, vector databases, component-based design, state management
